# TokenCount

**Примерно сколько токенов** в тексте — для чатов и промптов.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 7 — «ИИ»** · **день 43**.

---

## Что умеет

- оценка токенов на лету (пока печатаешь — счётчик обновляется)
- диапазон **min–max** (±15% и якорь по словам)
- отдельно учитывает **латиницу / кириллицу / смесь**
- **Из буфера** — вставить текст одной кнопкой

Это **эвристика**, а не точный `tiktoken` или счётчик конкретной модели.

## Установка

```powershell
git clone https://github.com/vlx0/TokenCount.git
cd TokenCount
pythonw -m tokencount
```

Или `start.bat` / `run_tokencount.pyw`.

Нужен **Python 3.10+** с tkinter (обычно уже есть в установке Windows). Внешних зависимостей нет — только stdlib.
